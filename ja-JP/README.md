# SilentSafe

SilentSafe は **SilentStudio** が手がける、個人向けのシステムセキュリティ保護ソフトウェアです。

- **バージョン**: v1.0.0
- **プラットフォーム**: Windows

> 本リポジトリはプロジェクト紹介のみを目的としており、**ソースコードは含まれません**。

## 機能

- ファイル安全スキャン（マルチスレッド並列 + Rust 高速化拡張）
- リアルタイムシステム監視（Windows システムサービスとして登録、失敗時自動再起動、ソフト終了後も保護継続）
- 隔離管理
- 挙動保護（プロセス / レジストリ / ネットワーク）
- 深い注入検出（ETW-TI）
- 保護はデフォルトで全オン、UI は結果のみ表示し技術的詳細は非表示

## 技術スタック

Python + PySide6 + QFluentWidgets + C++ スキャンエンジン + Rust 高速化拡張

## 技術アーキテクチャ

- **UI 層**: Python + PySide6 + QFluentWidgets、多ページナビゲーション（ホーム / 安全アドバイス / スキャン / リアルタイム保護 / 挙動保護 / 隔離 / 通知 / 設定）、ライト/ダークテーマとアクセントカラー、中英の即時言語切替。
- **スキャンエンジン**: C++（SilentSecurityEngine）、マルチスレッド並列スキャン、進捗と結果を改行区切り JSON（JSONL）でストリーム出力。単一ファイル / ディレクトリ / 全ドライブモード。
- **高速化拡張**: Rust（`ss_rust.pyd`、PyO3）がエンジンの JSONL 出力をバッチ解析・集約し、Python の行単位解析より約 3 倍高速。欠落時は純 Python に自動フォールバック（意味は同一）。
- **リアルタイム監視**: Windows `ReadDirectoryChangesW` イベント駆動、全固定ディスクを再帰監視。確認済みシグネチャヒットは自動削除、ヒューリスティックヒットは自動隔離。
- **挙動監視**: プロセス生成は ETW イベント駆動（0 遅延、`NtCreateProcess` 対応、不可時はポーリングにフォールバック）。レジストリ自動起動と外部（アウトバウンド）接続はスナップショット差分検出。イベントは PID / 親 PID / 挙動チェーンを保持。
- **システムサービス**: エンジンを Windows サービスとして登録（SCM 管理、自動起動）、失敗時自動再起動ポリシー（5s / 10s / 60s）。UI プロセスから分離し、終了後も保護継続、プロセスが強制終了されても SCM が自動起動。
- **サンドボックス**: 隔離に失敗した高リスク実行ファイルをサンドボックスプロセスで自動実行分析、収集した挙動で再判定し、悪性判定なら再度隔離を試行。
- **署名検証**: WinVerifyTrust によるオフライン Authenticode 検証 + 署名者抽出（失効確認なし・オフライン）。Microsoft / Google の有効署名は完全信頼してスキップ、他の有効署名は降格し署名者情報を付与。
- **深い注入検出**: ETW-TI（AutoLogger カーネルセッション、Windows 11）。
- **通信モデル**: UI とエンジンは JSONL で疎結合。スキャンは stdout パイプ、サービスモードでは監視 / 挙動イベントをイベントファイルに書き込み UI が増分ポーリング。
- **隔離**: ファイルを隔離ディレクトリに移動し再実行を防止、リスト / 復元 / 削除に対応。隔離・ログディレクトリはスキャン対象から除外し、誤再報告を防止。
